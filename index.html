手寫統一發票小幫手

免費的手寫統一發票開立輔助工具。輸入買受人、統一編號、品名與金額，自動計算銷售額、5% 營業稅與總計，產生中文大寫金額，並以發票格式即時預覽，方便照著填寫紙本發票。金額計算都在瀏覽器中完成；輸入 8 位數統一編號時，會向 g0v 公司登記查詢 API 查詢並帶入買受人名稱。

計算方式

  • 應稅（5%）：由含稅總計推算時，稅額 = 四捨五入(總計 − 總計 ÷ 1.05)，銷售額 = 總計 − 稅額；由未稅銷售額推算時，稅額 = 四捨五入(銷售額 × 0.05)。
  • 零稅率、免稅：稅額為 0，銷售額等於總計。

網址預填

可用網址參數預先帶入欄位：uniformNumber（統一編號）、amount（含稅總計）、itemName（品名），例如 /?uniformNumber=12345678&amount=1050&itemName=顧問費。

開立前檢查清單

  • 銷售額、營業稅額與總計金額三者相符，且無四捨五入誤差。
  • 課稅別（應稅、零稅率或免稅）與交易性質相符。
  • 統一編號與買受人名稱正確。
  • 品名描述清楚，數量與單價計算無誤。
  • 開立日期在當期（當月）內，避免跨期開立。
  • 使用藍色或黑色原子筆，字跡清晰且不得塗改；有錯誤請依規定作廢重開。

電子發票請改用 財政部電子發票整合平台。給 AI agent 的說明：llms.txt。
